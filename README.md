# Repaso JS

Ejercicios de JavaScript con repetición espaciada, al estilo de Anki. Son 82 tarjetas en 5 niveles. Mirás el código, respondés, tocás **Mostrar respuesta** y elegís **Otra vez**, **Difícil**, **Bien** o **Fácil**. Cada botón muestra cuándo vuelve la tarjeta.

## Niveles

1. Sintaxis básica
2. Condicionales, bucles, funciones y objetos
3. Trucos del lenguaje: coerción, hoisting, referencias, clausuras
4. Arrays y objetos modernos
5. Funciones en profundidad: `this`, `bind`, currying, recursión

## Usarla como app

La app es una página estática. Con GitHub Pages queda en `https://<tu-usuario>.github.io/<repositorio>/`.
Desde el celular, abrí esa dirección y elegí **Agregar a pantalla de inicio**.

## Guardar el progreso con tu cuenta

En **Progreso → Cuenta y copia de seguridad** pegás un token de GitHub con el permiso `gist`. La app crea un gist privado con tu progreso y lo mantiene sincronizado entre dispositivos. El token se guarda solo en el navegador. También podés descargar y cargar una copia en un archivo.

## Agregar ejercicios

Las tarjetas están en `cards.js`. `s(...)` es para predecir la salida de la consola y `e(...)` para explicar el código. También se pueden agregar desde la pestaña **Mazo**.
